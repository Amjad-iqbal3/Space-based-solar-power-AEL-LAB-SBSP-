# Space-based-solar-power-AEL-LAB-SBSP-
We formulate constellation-level power allocation as a two-tier scheduling problem and evaluate it in a physically grounded, E2E simulation of a 20-satellite Walker constellation beaming 2.45 GHz microwave power to an eight-station cluster, with propagation simulated over 24 hours using a coupled orbital, thermal, battery, and WPT channel model.
